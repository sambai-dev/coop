# Projects using Rookhold

No project is listed without its maintainer's permission. If Rookhold is part
of something you maintain, open a short pull request adding:

- project name and public link;
- the Rookhold use case;
- the tested Rookhold version; and
- a maintainer-approved one-sentence description.

Private users can share the same facts in
[Discussions](https://github.com/sambai-dev/rookhold/discussions) without naming
their project. This page will not infer use from download counts.

## What the project measures

Rookhold has no hidden telemetry. Maintainers use public package downloads,
release downloads, starter forks, external package references, contributors,
repeat support conversations, and opt-in reports as imperfect signals. The
useful outcome is repeat external jobs and applications, not a star count.
