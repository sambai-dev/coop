# Contribution tiers

Rookhold applies checks according to the code being changed.

- **Docs, examples, and integrations:** relevant formatting and a working example or configuration check.
- **SDK and public API:** unit and integration tests, compatibility review, changelog when needed, and a clean package install.
- **Executor, authentication, storage, receipts, and isolation:** RED reproduction, adversarial cases, exact-head evidence, hostile-job coverage, platform checks, and rollback analysis.

See [CONTRIBUTING.md](https://github.com/sambai-dev/rookhold/blob/main/CONTRIBUTING.md) for commands and review expectations.
