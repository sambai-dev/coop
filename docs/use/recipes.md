# Recipes

The repository's [examples directory](https://github.com/sambai-dev/rookhold/tree/main/examples)
contains small, CI-checked recipes for:

- generated functions;
- JSON transforms;
- hidden-test evaluation;
- stdin and structured output;
- timeout and cancellation;
- bounded files and returned artifacts;
- receipt saving and verification; and
- MCP host configuration.

Fork a complete surface from the
[Next.js starter](https://github.com/sambai-dev/rookhold/tree/main/templates/nextjs-code-runner)
or [FastAPI starter](https://github.com/sambai-dev/rookhold/tree/main/templates/fastapi-code-runner).
