# Dashboard execution desk

- Scope: replace the embedded `/` operator console visual world while preserving every existing API-backed workflow.
- Mode: Operate.
- Audience: one solo technical builder who submits short jobs, watches ordered execution, diagnoses failure, and exports server-reported evidence.
- Primary task: compose → queue → observe → inspect result/record.
- Approved comp: `.impeccable/mocks/chalk-carbon-execution-desk.png`.
- Seed key: `b6f33025`; the user's pinned hybrid direction overrides the roll.

## Direction

Chalk-white command planes surround one carbon execution well. The transcript is the focal object; the composer is always one action away and the proof sheet is contextual rather than equal-weight dashboard chrome. The memorable moment is the run progressing down a chronological intent → accepted policy → execution → output → completion → proof sequence.

## Typography and density

- Workhorse system humanist sans for operator labels; `14px` body with `12px` metadata and `16px` section titles.
- System monospace for code, IDs, hashes, time, status facts, and transcript payloads.
- Four-pixel spacing base. Dense controls use 8–12px internal spacing; major plane seams use 16–20px.
- Dynamic figures use tabular numerals.

## Responsive behavior

- Desktop: fixed 292px composer, flexible transcript, 310px result sheet when open.
- Compact desktop/tablet: composer stays available; result sheet overlays the transcript and returns focus on close.
- Mobile: one focused surface at a time. Compose and History open from the command bar; Result/Record is a bottom sheet; Back returns to the transcript.
- Sequence never changes: requested policy precedes observed posture, then portable server-reported proof.

## Constraints

- Preserve connect, identity context, create, search, filter, history, paginate, select, stream, cancel, output, events, result, record, copy, and exact-download behavior.
- Keep API keys in page memory only.
- Never imply that dashboard evidence was independently verified.
- No new agent/chat/analytics/billing capability, gradients, glass, card grid, decorative raster, or terminal-window chrome.
- Preserve keyboard navigation, visible focus, 320px reflow, reduced motion, forced colors, and explicit text status.
